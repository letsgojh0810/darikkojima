# Visual Quality — 펫·옷장 품질과 전수 검수

이 앱은 보이는 게 전부다. 펫 그림·옷·표정·설정 화면의 시각 품질이 곧 앱의 품질이므로 항상 최선의 완성도로 만든다. **속도보다 완성도.** 첫 결과물부터 완성도를 보장하고, 사용자가 결함을 찾게 만들지 않는다.

## Process

### Step 1: 시안이 필요한지 판단

| 변경 종류 | 처리 |
|-----------|------|
| 펫 생김새 변경, 새 펫·견종·색, 화면 구조 변경 | **시안 먼저** — 앱 코드를 바꾸기 전에 그려서 보여 주고, 통과 후 적용 |
| 위치 미세 조정, 크기, 색 한 톤, 기존 아이템 핏 수정 | 바로 적용 후 결과 이미지로 보고 |

시안은 현재 모습과 나란히, 여러 색·여러 방향(A/B/C)을 비교할 수 있게 만든다. "애매하다"면 방향을 바꿔 새 시안을 낸다.

### Step 2: 렌더링

- 임시 렌더 테스트 `src/zz-*.test.tsx`(renderToStaticMarkup → SVG) + Edge headless로 PNG 생성.
- **4배 이상 확대**. 한 장에 너무 많이 넣어 작게 보이거나 잘리면 나눠서 다시 찍는다.
- 설정 화면은 실제 창 크기(960×520)에서 라이트·다크 둘 다.

### Step 3: 검수 범위

| 축 | 범위 |
|----|------|
| 펫 | 고양이·강아지·토끼·로봇 전부. 공용 코드(FrontFace, Outfit)를 고치면 모든 펫 |
| 색·견종 | 펫마다 모든 색, 강아지는 견종 4종 |
| 상태 | 평소, 호버, 잔소리, 클릭, 잠자기 (+ 해당되면 드래그) |
| 옷 | 바뀐 아이템은 모든 펫×모든 상태. 펫 모양이 바뀌면 머리·얼굴·목 **전체 아이템** |

### Step 4: 체크리스트

```markdown
| # | Check | Result | Fix |
|---|-------|--------|-----|
| 1 | **위치·핏** — 모자는 머리에 얹힘, 안경은 눈에 맞음, 목 옷은 턱 아래에서 나옴 | ✅/❌ | |
| 2 | **방향** — 목걸이는 U자(뒤집힘 없음), 끈은 머리 안쪽 | ✅/❌ | |
| 3 | **겹침 없음** — 옷끼리, 옷과 볼터치·코·털·무늬 | ✅/❌ | |
| 4 | **가려짐 없음** — 털·화면·몸이 옷을 가리지 않음 | ✅/❌ | |
| 5 | **틈 없음** — 몸·턱과 옷 사이 빈틈 | ✅/❌ | |
| 6 | **잘림 없음** — 창 밖, 미리보기 칸, 높은 모자 | ✅/❌ | |
| 7 | **대비** — 흰 털 위 흰 옷, 어두운 털 위 어두운 선도 보임 (테두리) | ✅/❌ | |
| 8 | **잠자기** — 옷이 머리와 함께 기울어짐, 목 옷은 자연스럽게 숨음, 가방은 바닥에 | ✅/❌ | |
| 9 | **표정** — 눈은 잘 때만 감음, 클릭은 눈 뜬 채 웃음 | ✅/❌ | |
| 10 | **톤 일관성** — 외곽선 outline()·LINE_W, 옷 테두리 edge() | ✅/❌ | |
| 11 | **UI 일관성** — 같은 종류의 선택은 같은 UI (예: 견종도 색 동그라미) | ✅/❌ | |
| 12 | **재검수 완료** — 고친 뒤 다시 찍어서 확인함 | ✅/❌ | |
```

### Step 5: Verdict

| Result | Verdict |
|--------|---------|
| 12/12 | **보고** |
| ❌ 있음 | **수정 → Step 2부터 다시** — ❌가 남은 채로 보고하지 않는다 |

### Step 6: 정리와 보고

- 임시 파일(`zz-*`) 삭제.
- 보고에 적을 것: 확인한 범위, 확인 중 고친 것, **확인하지 못한 것**.

## Rules

1. **썸네일 한 장으로 판단하지 않는다** — 확대해서 하나씩 본다.
2. **고친 뒤 반드시 재검수** — 고쳤다는 말만으로 보고하지 않는다.
3. **큰 디자인 변경은 통과 전 적용 금지** — 시안 → 사용자 통과 → 적용.
4. **눈은 잘 때만 감는다** — 깨어 있을 때 깜빡임·눈 감는 표정(^^ 포함) 금지.
5. **잠자기는 실제로 자는 자세** — 펫마다 엎드리거나 몸을 만 고유 자세. 눈만 감는 것은 잠이 아니다.
6. **옷이 묻히면 펫 쪽을 바꾼다** — 예: 로봇은 밝은 화면, 포메라니안 가슴털은 목 옷 아래.
7. **스타일 통일** — 머리 하이라이트, 몸 그림자, 몽글한 가슴털, 발바닥 젤리(고양이·강아지), 눈 반사광.
8. **무한 반복 애니메이션 금지** — 투명 창에서 GPU 사용량이 오른다. 대기·잠은 정지 그림.
9. **설정 창을 키워서 해결하지 않는다** — 묶기·접기·시트로 해결.
