# UX Principles — 방해하지 않는 동료

펫은 사용자의 작업을 돕는 조용한 동료다. 사용자 경험을 해칠 가능성이 있는 변경은 넣지 않는다.

## Process

### Step 1: 변경 유형 확인

| 유형 | 먼저 할 일 |
|------|-----------|
| 재현되지 않는 버그 | 고치지 말고 재현 조건·관찰한 사실·가능한 원인을 보고하고 결정을 받는다 |
| 창·입력·알림 동작 변경 | 사용자 화면·작업을 가로막을 가능성이 있으면 먼저 묻는다 |
| 기본값 변경 | 이미 바꾼 사용자 값은 유지되는지 확인 |
| 설정 항목 추가 | 요청된 것인지, 기존 항목에 묶을 수 있는지 확인 |
| 레벨·옷 배치 변경 | 표로 제안 → 승인 후 적용 |

### Step 2: 체크리스트

```markdown
| # | Check | Result | Fix |
|---|-------|--------|-----|
| 1 | **추측성 우회 없음** — 주기적 강제 재설정, 폴링, 숨은 타이머로 증상을 덮지 않음 | ✅/❌ | |
| 2 | **방해 금지 시간 준수** — 근무 외·점심·전체화면·조용히 모드·회의 중 말 걸지 않음 | ✅/❌ | |
| 3 | **자리 비움 존중** — 10분 미입력이면 알리지 않고 펫은 잠, 돌아오면 간격 새로 시작 | ✅/❌ | |
| 4 | **말풍선이 쌓이지 않음** — 한 말풍선에 모으고, 대답 없으면 저절로 사라짐 | ✅/❌ | |
| 5 | **기본값은 실사용 기준** — 처음 설치한 사람이 그대로 써도 자연스러움 | ✅/❌ | |
| 6 | **사용자 값 보존** — 기본값을 바꿔도 사용자가 바꾼 값은 덮어쓰지 않음 | ✅/❌ | |
| 7 | **되돌리기 가능** — 바꾼 값을 쉽게 기본으로 되돌릴 수 있음 | ✅/❌ | |
| 8 | **설정이 늘지 않음** — 요청되지 않은 옵션·토글 없음, 늘면 묶음 | ✅/❌ | |
| 9 | **위험 동작은 두 단계** — 초기화 등 되돌릴 수 없는 동작은 확인 단계 | ✅/❌ | |
| 10 | **잠기는 옷 고지** — 레벨 변경으로 입던 옷이 잠기면 영향받는 사용자를 보고에 적음 | ✅/❌ | |
```

### Step 3: Verdict

| Result | Verdict |
|--------|---------|
| 전부 ✅ | **진행** |
| ❌ 있음 | **보류하고 사용자에게 확인** |

## Rules

1. **재현 안 되면 넘어간다** — 추측으로 우회 코드를 넣지 않는다. (사례: "2초마다 항상 위 재지정"을 넣었다가 v0.2.3에서 되돌림)
2. **사용자가 하지 않은 행동을 앱이 대신하지 않는다.**
3. **요청되지 않은 기능·옵션을 추가하지 않는다.**
4. **설정은 단순하게** — 탭을 늘리지 않는다(6탭 → 4탭으로 정리한 이유).
5. **옷 보상은 Lv.1·3·5·10에 아홉 벌씩, 숨은 옷은 칭호로** — 배치 변경은 제안 후 승인.
