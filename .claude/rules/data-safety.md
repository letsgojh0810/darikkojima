# Data Safety — 데이터 유실 금지와 개인정보

컴퓨터 재부팅, 앱 재시작, 업데이트 어떤 경우에도 사용자 데이터가 사라지거나 초기화되면 안 된다. 다른 어떤 기능보다 우선한다.

지켜야 할 데이터: 설정 전체, 펫 종류·이름·색(견종)·옷, 레벨·친밀도·숨은 옷·기록, 캘린더 주소와 이름, 펫 위치, 조용히 모드.

## Process

### Step 1: 영향 범위 파악

변경이 아래 중 하나라도 건드리면 이 규칙의 체크리스트를 전부 수행한다.

- `src/store/` (저장·읽기·기본값·`migrateSettings`)
- 저장되는 값의 id·키 이름 (펫 id, 색·견종 id, 아이템 id, 설정 키)
- 아이템 레벨·해금 조건
- 설치·업데이트 (`src-tauri/windows/hooks.nsh`, `tauri.conf.json`의 bundle·updater)
- 공개되는 산출물 (README, `docs/screenshots/`, 릴리즈 노트, 커밋 메시지)

### Step 4: 보고

데이터 경로·저장·마이그레이션을 건드렸으면, 보고에 "재시작·업데이트 후에도 값이 남는 근거"(테스트 이름, 코드 위치)를 적는다. 확인하지 못한 것은 못 했다고 적는다.

## Rules

1. **데이터 유실은 어떤 이유로도 허용하지 않는다** — 기능 편의, 코드 단순화, 리팩토링이 이유가 될 수 없다.
2. **저장 구조를 약화시키지 않는다** — `src/store/index.ts`의 이중 저장·복구·쓰기 차단은 제거·단순화 금지.
3. **id를 바꾸면 반드시 옮긴다** — 이동 코드와 테스트 없이 저장 값 이름을 바꾸지 않는다.
4. **사용자 선택은 같은 의미의 값으로만 옮긴다** — 임의로 다른 값으로 바꾸거나 초기화하지 않는다.
5. **`npm run tauri dev` 금지** — 설치한 앱의 실제 데이터를 쓴다.
6. **비밀 정보는 출력하지 않는다** — ICS 주소, 서명 키(`~/.tauri/darikkojima.key`, GitHub secret `TAURI_SIGNING_PRIVATE_KEY`).
7. **공개물에 개인정보 없음** — 실제 일정, 실명. 애매하면 사용자에게 직접 찍게 한다.
